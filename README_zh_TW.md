# AcademyCraft NeoForge 1.21.1

這是 AcademyCraft 的 Minecraft 1.21.1／NeoForge 原生移植版。

> UI、遊戲本體、技能 Context 與視覺行為以 Forge 1.12.2／AcademyCraft 1.1.3 為主要移植來源；Git 標籤 `1.0.7` 僅用於校對穩定 ID、保留內容與平衡歷史。

## 編譯

需要 Java 21：

```bash
./gradlew test
./gradlew build
```

輸出位於 `build/libs/AcademyCraft-neo-1.21.1-2.0.1.jar`。

## 安裝

1. 安裝 **Minecraft Java Edition 1.21.1**、**NeoForge 21.1.242 或更新的 21.1.x**，並以 **Java 21** 啟動。
2. 將 `AcademyCraft-neo-1.21.1-2.0.1.jar` 放入遊戲實例的 `mods` 目錄。
3. 客戶端與多人伺服器都必須安裝相同 JAR；建議建立新世界，舊版存檔不支援轉換。

## 基本操作

- `V`：短按啟用／解除能力；長按顯示計算力資料。
- 滑鼠左鍵、滑鼠右鍵、`R`、`F`：使用四個能力預設欄位。
- 左 `Alt`：開啟資料終端。
- `N`：開啟能力預設編輯／技能樹。
- `C`：切換四組能力預設；每組各有四個技能欄位。
- 以便攜、普通或高階能力開發機執行類別開發、升級與技能學習；持有的「能力誘導因子」會指定首次取得的類別。
- 類別進度達 100% 後，仍須在開發機中執行升級。高階開發機搭配磁力線圈與不同類別的誘導因子可轉換類別。
- 資料終端技能樹用於檢視技能及調整預設，不會繞過開發機直接學習技能。
- 對普通／高階開發機 Shift＋右擊可開啟其能量物品欄。
- 能量單元右擊機器會由機器充電；Shift＋右擊會將能量輸入機器。
- 安裝「頻率傳輸器」App 後，可為矩陣建立有密碼的網路，並授權節點與機器加入。
- 「位置傳送」會開啟具命名、刪除及跨維度熟練度限制的儲存位置介面。

完整架構變更請見 [`PORTING.md`](PORTING.md)。本移植不支援 1.7.10／1.12.2 舊存檔轉換，請建立新的 Minecraft 1.21.1 世界。
